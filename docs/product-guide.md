# 产品指南

先上手，再看每个面板的细节与几条常见配方。

## 快速上手

1. **打开工作台**：任意会话右上角的终端图标 → 出现「远程主机」标签。它与内置「文件」标签并排，宽度、分栏、全屏都由 DSH 管理。
2. **连接服务器**：点服务器条上的 **＋**。
   - 已有资源：从下拉里选一台，直接「连接并打开」。
   - 第一次连：填主机、端口、用户名，选密码或私钥。想以后复用就点「保存并连接」——凭据只写进本机凭据库。
3. **在对话里用**：不必告诉模型连接 ID。直接说「看下磁盘和内存」「把 nginx 配置发我看下」，它会在当前连接上执行，命令与输出同步出现在你面前的终端里。
4. **想先看机器状态时**：切到「状态」标签，CPU、内存、磁盘、网络、GPU、进程一屏看完（见下）。
5. **需要文件时**：切到「文件」标签，进目录、双击下载、拖文件进来上传；编辑文本用行尾菜单的「编辑」。想在同一个目录里敲命令就点「在终端打开」。
6. **需要转发时**：切到「转发」标签，把服务器能访问的端口带到本机，或把本机端口暴露给服务器。

## 面板

### 服务器条
- 每个标签是一个**已打开的连接**，圆点表示**本对话**的终端是否存活：别的对话在同一个连上有终端，不会让你的圆点变绿。
- 带「Agent」徽标的那条是**本对话**模型当前的作用目标。点另一条即把本对话的 Agent 切过去；切换由宿主确认，失败时保留原目标并报错。别的对话点哪台服务器，与你无关。
- 只有**没有任何分栏**还在显示这台服务器时，关闭标签才真正断开。分栏两边各开一次会得到两条独立通道，互不影响。
- 右上角的盾形按钮是 **AI 命令执行策略**（标准 / 自定义 / 全部放行）。放宽需要二次确认，且只在本会话有效，重连即恢复。

### 状态
- 一屏五组读数，顺序固定：CPU（总量 + 负载 + 每核）、GPU（NVIDIA）、内存与 swap、磁盘（用量 + 读写速率）、网络（每接口 ↓↑），再加进程 Top 与本连接的服务器/地址/采样耗时。
- 默认 2 秒采样，页脚可切 2 / 5 / 10 秒或暂停；切到别的标签、收起侧栏或窗口隐藏时自动停表，不会白烧 SSH 通道。
- 读数来自宿主侧一条固定的只读脚本（`/proc`、`df`、`ps`、`nvidia-smi`），不需要远端装任何东西，也不需要 sudo。
- 取不到就说明原因：非 Linux 远端、没有 exec 通道的网络设备、sshd 的 `MaxSessions` 用满时，面板会写清楚，而不是显示 0；首拍还没形成间隔时显示「采样间隔尚未完成」。
- 进程的 CPU% 是 `ps` 的生命周期平均，不是瞬时值——面板里直接写明了这一点，看瞬时占用请以总量和每核为准。
- 在容器里看到的是宿主口径：`/proc` 与 `df` 报的是宿主的 CPU、内存与底层文件系统，cgroup 配额不在其中（容器根 `/` 仍会显示，不会因为设备名是 `overlay` 被过滤掉）。
- 页脚的复制按钮把当前读数整理成一段文本（服务器、CPU、内存、磁盘、网络、GPU、采样时间），可以直接粘进对话里让模型接着分析。

### 终端
- **每个对话各自一个终端**：同一台服务器在两个对话里各开一个，输入、输出、当前目录互不干扰；Agent 只读写自己对话的终端。面板只显示本对话的终端——服务器上还有别的对话的终端时，空态会告诉你有几个。
- 唯一例外是显式合并：连接对话框里勾「复用已打开的连接」，该连接才会被多个对话共享（此时终端也是同一个）。
- 一个对话结束（关闭/删除该对话）时，它在各服务器上的终端随之关闭。
- 会话归宿主，终端归浏览器：切标签、收起侧栏、换会话都不会断开，回来时回看还在。
- `Ctrl/⌘+F` 查找，`Shift+Enter` 反向；选中即复制；`Ctrl+滚轮` 缩放字号。
- 内容滚出上方时，右下角出现「滚到底部」。
- 调色盘按钮打开外观设置：跟随 DSH 或固定深浅主题、自定义背景、可选的语义高亮（默认关闭）。

### 文件
- 面包屑可点击跳转；`..` 行返回上级。
- 编辑文本时先取原内容比对，保存前在远端同目录留一份备份；保存失败不会覆盖。
- 上传目录默认合并同名目录；遇到冲突可选跳过 / 保留两份 / 覆盖，并对剩余项批量应用。
- 大文件下载走流式通道（宿主提供 Web 服务时），可看到进度、速度与剩余时间。

### 转发
- **本地**：把服务器能访问的端口带到本机，例如 `127.0.0.1:13306 → 10.0.0.31:3306`。
- **远程**：把本机端口暴露给服务器，例如让服务器访问你本机的 webhook 接收器。
- **动态**：在本机开一个 SOCKS5 代理，出口是这台服务器。
- 绑定端口留空或填 0 由系统分配，列表显示实际端口。隧道随连接存活，断开即全部关闭。

### 快捷命令
- 点击**只填入输入行**，命令不会自己跑；`Enter` 仍由你按。
- 自定义命令支持 `{{参数}}`，填入前会先询问参数并预览完整命令。
- 作用域可以是所有服务器 / 指定分组 / 指定服务器。

### 日志
- 每次终端会话在宿主侧留一份记录，可按块读取、搜索、下载为纯文本、按条删除。
- 记录里可能有敏感内容，按需清理。

## 设置 → 远程主机

| 分区 | 作用 |
| --- | --- |
| 服务器 | 分组、搜索、编辑、跳板链、固定项目目录、远程工作区绑定、OpenSSH 导入、加密备份导入导出 |
| 共享凭据 | 一份密码 / 私钥供多台服务器与跳板共用；仍被引用的凭据不能删除 |
| 已信任主机 | 每个主机的指纹与「忘记」；指纹变化会拒绝连接，直到你确认 |
| AI 策略 | 自动连接开关、执行策略、放行规则 |
| 功能 | 分别开关转发 / 日志 / 状态工具与右侧面板标签（改完需重启 DSH） |

从「服务器 → 从 SSH 配置导入」读取宿主 `~/.ssh/config` 时，每个主机的 `IdentityFile` 私钥会随服务器一起写入本机凭据库：预览会标出「自动导入私钥 / 需填口令 / 无法导入」，加密私钥导入后只需补填口令。私钥文件有没有扩展名都可以直接选择。

## 配方

**一句话看机器状态。** 直接说「这台机器现在怎么样」「磁盘还剩多少」，模型会调用 `ssh_status` 读同一份归一化采样（与「状态」标签同源），不用你自己敲 `top` / `df`；也可以从状态页复制快照再追问。

**让模型跑一条有风险的命令。** 直接说「清理 /tmp 下三小时前的日志」。命令命中安全规则时会挂起等待批准；批准后执行的是移入 `~/.dsh-trash/`，之后可以用 `mv` 放回原处。

**同一台机器开两个窗格。** 在 DSH 侧栏里分栏，然后各自连接同一台服务器：默认各建一条独立通道（各自 cwd 与终端）；想共用一个终端，在连接对话框勾「复用已打开的连接」。

**两个对话并行操作同一台机器。** 直接开两个对话，各自连接它即可：两个对话各有自己的终端与 Agent 目标，A 里的命令不会出现在 B 的终端里，B 的 Agent 也读不到 A 的屏幕。

**跨电脑迁移服务器清单。** 设置 → 服务器 → 导出加密备份（独立口令加密，含分组、共享凭据、跳板关系与已信任指纹）；在另一台机器导入会新增服务器并复用同名分组，不覆盖已有条目。
